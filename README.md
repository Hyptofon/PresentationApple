# Interactive Apple-Style Presentation

A cinematic, highly interactive web-based presentation exploring the Apple Ecosystem and its marketing strategies. This project was built to deliver a "wow" factor, moving away from static presentation slides into a fully immersive, dynamic user experience.

## ✨ Features

- **Cinematic Apple Aesthetics:** Premium dark mode, frosted glassmorphism (glass cards), deep glowing gradients, and gorgeous typography.
- **Interactive "Wow" Moments:**
  - **Theater Mode:** An interactive hardware mock-up (Pro Display XDR) that dims the lights and expands the video player for a fully immersive viewing experience.
  - **The Halo Effect:** Animated light rays beaming from a central iPhone to connected accessories, visualizing product synergy.
  - **The Standoff Scale:** An autonomous, breathing 3D scale visualizing the debate between "Pure Magic" and "Golden Handcuffs" to drive audience discussion.
  - **Secure Vault:** A visual iPhone teardown showcasing "trapped" user data to explain privacy marketing.
- **Scroll-Driven Animations:** Smooth transitions, fade-ins, and scaling effects that trigger exactly when the presenter reaches the slide.
- **Responsive Layouts:** Perfectly scaled cinematic 2-column designs that adapt cleanly.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Animations:** Custom CSS Keyframes & React Hooks

## 🚀 How to Run Locally

If you want to run this presentation on your own machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Hyptofon/PresentationApple.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) in your browser.

*Press `F11` (or your browser's fullscreen shortcut) for the best cinematic experience.*
